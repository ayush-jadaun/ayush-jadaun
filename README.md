<summary><b>🤖 MarlOS - Multi-Agent Reinforcement Learning Operating System</b></summary>

<div align="center">
  <img src="https://socialify.git.ci/ayush-jadaun/MarlOS/image?font=KoHo&forks=1&issues=1&language=1&name=1&owner=1&pattern=Floating%20Cogs&pulls=1&stargazers=1&theme=Dark" alt="MarlOS Socialify Banner" width="640" />
  <br/>
  <img src="https://skillicons.dev/icons?i=python,pytorch,docker,redis,mongodb" alt="MarlOS Tech Stack" />
</div>

**MarlOS** is a decentralized, fairness-aware distributed computing operating system that removes the need for centralized orchestrators like Kubernetes.

-   **Core Features:**
    -   🔐 **Fully Decentralized P2P Network:** No master node; peer discovery via ZeroMQ with Ed25519 cryptographic security.
    -   🧠 **RL-Based Bidding:** Each node runs a PPO agent that decides to Bid, Forward, or Defer tasks based on a 25-dimensional state vector.
    -   💰 **Token Economy (MarlCredits):** Fairness-aware economic layer with adaptive tokenomics, trust & reputation system, progressive taxation + UBI.
    -   🛡️ **Self-Healing Runtime:** Detects node failure and automatically migrates active jobs to backup nodes with quorum consensus.
    -   🔮 **Speculative Execution:** Predictive agent anticipates likely future jobs and executes them in advance for zero-latency responses.
    -   🐳 **Extensible Job Runners:** Supports shell, Docker, and cybersecurity tasks (malware_scan, vuln_scan, hash_crack, forensics).
-   **Goal:** To revolutionize distributed computing with autonomous, fair, and self-regulating computational swarms without central authority.
-   **Tech Stack:** Python, PyTorch, Stable Baselines3, ZeroMQ, Ed25519, Docker, Redis, SQLite.
-   **Links:** [GitHub Repository](https://github.com/ayush-jadaun/MarlOS) | [PyPI Package](https://pypi.org/project/marlos/) | [Demo Video](https://youtu.be/EGv7Z3kXv30) | [Presentation](https://www.canva.com/design/DAG4KrB5-D0/W-mglhEG6lW3rpzn7PW4BA/view)

</details>

<summary><b>✈️ TBuddy - AI Travel Planning Platform</b></summary>

<div align="center">
  <img src="https://socialify.git.ci/ayush-jadaun/tbuddy/image?font=KoHo&forks=1&issues=1&language=1&name=1&owner=1&pattern=Floating%20Cogs&pulls=1&stargazers=1&theme=Dark" alt="TBuddy Socialify Banner" width="640" />
  <br/>

</div>

**TBuddy** is an AI-powered travel planning system using Redis-orchestrated multi-agent architecture for intelligent itinerary generation.

-   **Core Features:**
    -   🤖 **Multi-Agent Orchestration:** 5 specialized AI agents (Weather, Events, Maps, Budget, Itinerary) working in parallel via Redis pub/sub.
    -   ⚡ **Real-time Streaming Updates:** Live progress notifications using Server-Sent Events (SSE) as each agent completes its work.
    -   🌍 **Comprehensive Travel Intelligence:** Weather forecasts, local events, route optimization, budget planning, and day-by-day itineraries.
    -   📡 **Message Communication Protocol (MCP):** Standardized request/response format across all agents with fault tolerance.
    -   🔄 **Session State Management:** Resume planning sessions, track progress, cancel ongoing requests with Redis-backed state.
    -   🐳 **Horizontally Scalable:** Each agent runs in isolated Docker containers with configurable replicas for high throughput.
    -   📚 **Python Library Available:** Published `tbuddy` package on PyPI for easy integration into other projects.
-   **Goal:** To provide intelligent, personalized travel planning with real-time updates and comprehensive itinerary generation.
-   **Tech Stack:** Python, FastAPI, Redis, Google Gemini AI, Docker, OpenWeather API, OpenRouteService, React.
-   **Links:** [GitHub Repository](https://github.com/ayush-jadaun/tbuddy) | [PyPI Package](https://pypi.org/project/tbuddy/)

</details>
